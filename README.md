# Project Sprint — Swadeshi AI Phone Tracker

How far is India from a 100% indigenous AI phone? A single-page, dependency-free tracker of the smartphone stack (chips, modem, memory, display, camera, battery, boards, OS, AI models, brands) with a milestone progress line, companies, investments, an India map, history, past attempts and open opportunities.

Live at https://projectsprint.vokalglobe.com — served by GitHub Pages from `main`.

To update figures, edit the data arrays at the top of the `<script>` block in `index.html` (`LAYERS`, `MILESTONES`, `OPPS`, `GAPS`, `SCHEMES`, `ISM`, `SITES`, `PLAYERS`, `TIMELINE`, `ATTEMPTS`, `CHECK`).
